# The 3D Models of Back Cover for S1VirtualFloppy

    S1BackSideVF.FCStd ........ 3D model design file using FreeCAD 1.0

    S1BackSideVF-Body.stl ..... Exported 3d model from FreeCAD
    S1BackSideVF-Body.wrl ..... Exported 3d model from FreeCAD (to use on kicad 3d view)

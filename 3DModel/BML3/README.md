# 背面カバーの3Dモデル for L3VirtualFloppy

    L3BackSideVF2.FCStd ....... FreeCAD 1.0を使用した3Dモデル設計ファイル
    L3BackSideVF2-Body.3mf .... UltiMaker Cura 5.9の設定ファイル
    L3BackSideVF2-Body.stl .... FreeCADからエクスポートした3Dモデル
    L3BackSideVF2-Body.wrl .... FreeCADからエクスポートした3Dモデル(kicad 3Dビューで使用)

# The 3D Models of Back Cover for L3VirtualFloppy

    L3BackSideVF2.FCStd ....... 3D model design file using FreeCAD 1.0
    L3BackSideVF2-Body.3mf .... Configure file on UltiMaker Cura 5.9
    L3BackSideVF2-Body.stl .... Exported 3d model from FreeCAD
    L3BackSideVF2-Body.wrl .... Exported 3d model from FreeCAD (to use on kicad 3d view)
    MegaZero2.0/ .............. Gcode for 3D printer (Anycube Mega Zero 2.0)

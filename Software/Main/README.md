# バーチャルフロッピーカード for 日立ベーシックマスターレベル3 / MB-S1

## 使用ツール

 * VS Code
   + Raspberry Pi Pico SDK

## ビルド方法

 * 日立ベーシックマスターレベル3用のファームウェアをビルドする場合は、VS Code
   からpico_l3フォルダを開いてください。
 * 日立MB-S1用のファームウェアをビルドする場合は、VS Codeからpico_s1フォルダ
   を開いてください。

## フォルダ構成

    pico_l3/ ....................... 日立ベーシックマスターレベル3用
      build/ ......................... ビルド済みファームウェア
    pico_s1/ ....................... 日立MB-S1用ビルド
      build/ ......................... ビルド済みファームウェア
    src/ ........................... ソースコード

# Virtual Floppy Card for HITACHI Basic Master Level3 / MB-S1

## Using Tools

 * VS Code
   + Raspberry Pi Pico SDK

## How to build

 * If you're building firmware for the Hitachi Basic Master Level3, open
   the pico_l3 folder in VS Code.
 * If you're building firmware for the Hitachi MB-S1, open the pico_s1 folder
   in VS Code.

## Folders

    pico_l3/ ....................... for HITACHI Basic Master Level3
      build/ ......................... Built firmware
    pico_s1/ ....................... for HITACHI MB-S1
      build/ ......................... Built firmware
    src/ ........................... Source codes

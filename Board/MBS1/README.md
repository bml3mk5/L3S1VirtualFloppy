# 基板設計 for S1VirtualFloppy

 * KiCAD 8

## ファイル

    S1VirtualFloppy.kicad_pro ..... プロジェクトファイル for KiCAD
    S1VirtualFloppy.kicad_sch ..... 回路図ファイル for KiCAD
    S1VirtualFloppy.kicad_pcb ..... PCB設計ファイル for KiCAD
    *.kicad_sym ................... シンボルファイル
    *.pretty/ ..................... フットプリントファイル
    *.wrl ......................... 3Dモデルファイル(3Dビュー用)

# 基板設計 for コントローラー

## 使用ツール

 * KiCAD 8

    I2C_LED_BTN_CH32V.kicad_pro ... プロジェクトファイル for KiCAD
    I2C_LED_BTN_CH32V.kicad_sch ... 回路図ファイル for KiCAD
    I2C_LED_BTN_CH32V.kicad_pcb ... PCB設計ファイル for KiCAD
    *.pretty/ ..................... フットプリントファイル
    *.wrl ......................... 3Dモデルファイル(3Dビュー用)
    gerber_jlc/ ................... ガーバーファイル for JLCPCB

# The Circuit Board Design for Controller

## Using Tools

 * KiCAD 8

    I2C_LED_BTN_CH32V.kicad_pro ... Project file for KiCAD
    I2C_LED_BTN_CH32V.kicad_sch ... Schematics file for KiCAD
    I2C_LED_BTN_CH32V.kicad_pcb ... PCB design file for KiCAD
    *.pretty/ ..................... Footprint files
    *.wrl ......................... 3Dmodel file(to use on 3D view)
    gerber_jlc/ ................... Gerber files for JLCPCB
